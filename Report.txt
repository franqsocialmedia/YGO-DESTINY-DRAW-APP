## 4. DEPENDENCIAS ENTRE MÓDULOS

```
data.js (ConfigManager)  ←── buscador, mideck, historial, estadisticas,
                               simuladores, formacion, core (ContentManager)

data.js (Stats)          ←── estadisticas (cálculo de rendimientos decrecientes)

core.js (ContentManager) ←── formacion (applyProfile al cambiar perfil)
                               navigation applyAll() en cada tab change

mideck.js (Engines)      ←── Favoritas.render() delega si _activeTab='favoritas'
                               Staples: usa campo imageUrl (NO img)

historial.js (Duelista)  ←── lee matchup_${deckName} de todos los decks
                               requiere Deck.getSavedDecks()

formacion.js (Meta)      ←── Sub-tabs Fuentes y Maestros de Formacion delegan a
                               Meta._renderFuentesSection() / _renderMaestrosSection()

formacion.js (Welcome)   ←── llama ConfigManager.savePlayerLevel() Y
                               ContentManager.applyProfile() al hacer enter()

default_data.js          ←── requiere ConfigManager, Deck, Engines, Formacion,
(DefaultData)                 Meta, Banlist (todos ya cargados antes en index.html)
                               Parchea Config.resetToDefault al final del load.
```

## 5. FLUJOS CRÍTICOS

### 5.1 Cambio de pestaña
```
switchTab(name) → Navigation.showTab(name)
  → oculta todos .tab-content, activa #name-content
  → si mideck:            Engines.init()
  → si simuladores:       Torneo.init()
  → si formacion:         Formacion.init()
  → si meta:              Meta.init()
  → si saliendo de simuladores: ZonaPractica._cleanupFloatBtns()
  → Estadisticas.updateFloatingWidgetVisibility(tabName)
  → ContentManager.applyAll()
  → window.scrollTo({ top:0, behavior:'smooth' })
```

### 5.2 Selección de perfil (Welcome)
```
Welcome.enter(tabName, levelKey)
  → ContentManager.applyProfile(levelKey)  → 'dd_player_profile'
  → ConfigManager.savePlayerLevel(levelKey) → 'yugioh_player_level'
  → MusicPlayer.setTrack(cfg.tracks[levelKey])
  → Welcome.dismiss() → localStorage 'dd_welcome_dismissed' = 'true'
  → Navigation.showTab(tabName)
```

### 5.3 Selección de perfil (Config)
```
Config.selectPlayerLevel(levelKey)
  → ConfigManager.savePlayerLevel(levelKey)
  → ContentManager.applyProfile(levelKey)
  → MusicPlayer.setTrack(...)
  → Config.render()
```

### 5.4 Borrar Todo
```
Config.borrarTodo()
  → localStorage.clear() completo (flags de DefaultData desaparecen)
  → Welcome.dismissed = false
  → localStorage.removeItem('dd_welcome_dismissed')
  → reconstruye config vacía
  → Deck.render(), Estadisticas.render(), Favoritas.render()
  → Welcome.init() → muestra panel de nuevo
```

### 5.5 Restaurar Config (DefaultData)
```
Config.resetToDefault()  ← parcheado por DefaultData._patchConfig()
  → localStorage.clear()
  → await DefaultData.init()  → re-inyecta TODO (flags limpios)
```

### 5.6 DefaultData.init() — inyección única por tipo
```
window.load → DefaultData.init()
  → _initNotes()       si no flag dd_default_notes_loaded
  → _initSpecialties() si no flag dd_default_specialties_loaded
  → _initGames()       si no flag dd_default_games_loaded
  → _initMasters()     si no flag dd_default_masters_loaded
  → _initDecks()       si no flag dd_default_decks_loaded  (fetch API por ID)
  → _initStaples()     si no flag dd_default_staples_loaded (fetch API)
  → _initEngines()     si no flag dd_default_engines_loaded (fetch API)
  → _initGenesys()     si no flag dd_default_genesys_loaded (fetch API completa)
→ DefaultData._patchConfig()  → sobreescribe Config.resetToDefault
```

### 5.7 Botón flotante de música (MusicPlayer.toggle)
```
▶ (detenido) → MusicPlayer.toggle()
  → lee ConfigManager.getPlayerLevel() → resuelve cfg.tracks[level]
  → si path ≠ currentPath: _buildAudio(path) + play
  → si path == currentPath: play directo
  → _updateButton() → '⏹'

⏹ (reproduciendo) → MusicPlayer.toggle()
  → lee ConfigManager.getPlayerLevel() → resuelve cfg.tracks[level]
  → pause()
  → si path ≠ currentPath: _buildAudio(path)  ← pista actualizada, lista para próximo play
  → si path == currentPath: audio.currentTime = 0
  → _updateButton() → '▶'
```
**Nota:** cambiar Perfil Base en Config llama `MusicPlayer.setTrack(path)` que actualiza
`currentPath` en caliente. El toggle siempre re-verifica el perfil activo.

### 5.8 Render sidebar Mi Deck
```
Engines._renderSidebar()
  → lee _activeTab (engines|decks|staples|favoritas)
  → staples: _renderStaplesItems() → imageUrl (NO img)
  → favoritas: _renderFavoritasItems() → Favoritas.getAll()
```

## 10. NOTAS PARA TRABAJAR EFICIENTEMENTE

**Para cambios puntuales:** sube solo la función afectada indicando objeto y método. Ej: `Engines._renderStaplesItems` en `mideck.js`.

**Para CSS:** todos los ajustes responsive van exclusivamente en `responsive_style.css`. Los 5 archivos principales no tienen `@media`.

**Archivos que NO necesitas subir salvo cambios:**
- `html2canvas_min.js` — librería externa
- `logger.js` — solo si cambia la lista `TARGETS` o el formato del reporte

**Variables CSS globales** (definidas en `style_core.css`):
`--gold-color` · `--accent-color` · `--bg-card` · `--text-light` · `--danger-color` · `--spacing-sm/md/lg`

**Objetos renombrados respecto a versiones anteriores:**
- `Duelo` → `DueloEnVivo` (simuladores.js)
- `dd_power_scores_cache` → `yugioh_power_cache` (localStorage)
- `Stats` ahora vive dentro de `data.js` (no archivo propio)
- `default_data.js` es módulo nuevo; carga DESPUÉS de `formacion.js` y ANTES de `logger.js`

## 4. FLUJOS CRÍTICOS

### 4.1 Cambio de pestaña (navigation.showTab)
```
switchTab(name)
  → oculta todos .tab-content
  → activa #name-content
  → activa botón nav
  → si mideck: Engines.init()
  → si simuladores: Torneo.init()
  → si formacion: Formacion.init()
  → si meta: Meta.init()
  → ContentManager.applyAll()
  → Estadisticas.updateFloatingWidgetVisibility()
```

### 4.2 Render del sidebar de Mi Deck (Engines._renderSidebar)
```
Engines._renderSidebar()
  → lee _activeTab (engines|decks|staples|favoritas)
  → si engines: lista de engines guardados
  → si decks: lista de decks guardados con botón cargar
  → si staples: _renderStaplesItems() → ConfigManager.getStaples()
  → si favoritas: _renderFavoritasItems() → Favoritas.getAll()
  → IMG de staples usa campo: s.imageUrl (NO s.img)
```

### 4.3 Selección de perfil
```
Welcome Panel → Config.selectPlayerLevel(key)
  → ConfigManager.savePlayerLevel(key)   → 'yugioh_player_level'
  → ContentManager.applyProfile(key)     → 'dd_player_profile' [PENDIENTE en welcome.js]
  → MusicPlayer.setTrack(...)
  → Config.render()

Config UI → Config._applyProfileUI(key) → ContentManager.applyProfile(key)
  → [NO llama ConfigManager.savePlayerLevel] [PENDIENTE]
```

### 4.4 Borrar Todo (Config.borrarTodo)
```
→ localStorage.clear() completo
→ Welcome.dismissed = false
→ localStorage.removeItem('dd_welcome_dismissed') [PENDIENTE]
→ reconstruye config vacía
→ Deck.render(), Estadisticas.render(), Favoritas.render()
→ Welcome.init() → muestra panel de nuevo
```

## 8. API EXTERNA

**YGOProDeck API** (sin autenticación, CORS libre)
```
Base: https://db.ygoprodeck.com/api/v7/

Endpoints usados:
GET cardinfo.php?name=NOMBRE           → búsqueda por nombre
GET cardinfo.php?id=ID                 → carta por ID
GET cardinfo.php?fname=TEXTO           → búsqueda fuzzy
GET archetypes.php                     → lista de arquetipos
GET cardsets.php                       → lista de sets

Imágenes:
https://images.ygoprodeck.com/images/cards/{id}.jpg           → full
https://images.ygoprodeck.com/images/cards_small/{id}.jpg     → small
https://images.ygoprodeck.com/images/cards/back.jpg           → back (CARD_BACK)
```

## 10. NOTAS PARA TRABAJAR EFICIENTEMENTE

**Para cambios en un módulo:**
- Sube SOLO la función/método relevante, no el archivo completo
- Indica el nombre del objeto y método: ej. `Engines._renderStaplesItems`

**Para bugs de sync entre módulos:**
- Indica qué localStorage key espera cada lado
- Las claves `yugioh_player_level` y `dd_player_profile` DEBEN escribirse siempre juntas

**Para CSS:**
- `style_mideck.css` es el más grande y frágil — cerrar todos los `@media` correctamente
- Variables globales están en `style_global.css`: `--gold-color`, `--accent-color`, `--bg-card`, etc.

**Archivos que NO necesitas subir salvo cambios:**
- `html2canvas_min.js` — librería externa, no modificar
- `logger.js` — estable, no cambia
- `parallax.js` — estable, no cambia
- `utils.js` — estable, no cambia

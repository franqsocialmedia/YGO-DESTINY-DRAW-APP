## 5. FLUJOS CRÍTICOS

### 5.1 Cambio de pestaña
```
switchTab(name) → Navigation.showTab(name)
  → oculta todos .tab-content, activa #name-content
  → si mideck:            Engines.init()
  → si simuladores:       Torneo.init()
  → si formacion:         Formacion.init()
  → si meta:              Meta.init()
  → si saliendo de simuladores: ZonaPractica._cleanupFloatBtns()
  → Estadisticas.updateFloatingWidgetVisibility(tabName)
  → ContentManager.applyAll()
  → window.scrollTo({ top:0, behavior:'smooth' })
```

### 5.2 Selección de perfil (Welcome)
```
Welcome.enter(tabName, levelKey)
  → ContentManager.applyProfile(levelKey)  → 'dd_player_profile'
  → ConfigManager.savePlayerLevel(levelKey) → 'yugioh_player_level'
  → MusicPlayer.setTrack(cfg.tracks[levelKey])
  → Welcome.dismiss() → localStorage 'dd_welcome_dismissed' = 'true'
  → Navigation.showTab(tabName)
```

### 5.3 Selección de perfil (Config)
```
Config.selectPlayerLevel(levelKey)
  → ConfigManager.savePlayerLevel(levelKey)
  → ContentManager.applyProfile(levelKey)
  → MusicPlayer.setTrack(...)
  → Config.render()
```

### 5.4 Borrar Todo
```
Config.borrarTodo()
  → localStorage.clear() completo (flags de DefaultData desaparecen)
  → Welcome.dismissed = false
  → localStorage.removeItem('dd_welcome_dismissed')
  → reconstruye config vacía
  → Deck.render(), Estadisticas.render(), Favoritas.render()
  → Welcome.init() → muestra panel de nuevo
```

### 5.5 Restaurar Config (DefaultData)
```
Config.resetToDefault()  ← parcheado por DefaultData._patchConfig()
  → localStorage.clear()
  → await DefaultData.init()  → re-inyecta TODO (flags limpios)
```

### 5.6 DefaultData.init() — inyección única por tipo
```
window.load → DefaultData.init()
  → _initNotes()       si no flag dd_default_notes_loaded
  → _initSpecialties() si no flag dd_default_specialties_loaded
  → _initGames()       si no flag dd_default_games_loaded
  → _initMasters()     si no flag dd_default_masters_loaded
  → _initDecks()       si no flag dd_default_decks_loaded  (fetch API por ID)
  → _initStaples()     si no flag dd_default_staples_loaded (fetch API)
  → _initEngines()     si no flag dd_default_engines_loaded (fetch API)
  → _initGenesys()     si no flag dd_default_genesys_loaded (fetch API completa)
→ DefaultData._patchConfig()  → sobreescribe Config.resetToDefault
```

### 5.7 Botón flotante de música (MusicPlayer.toggle)
```
▶ (detenido) → MusicPlayer.toggle()
  → lee ConfigManager.getPlayerLevel() → resuelve cfg.tracks[level]
  → si path ≠ currentPath: _buildAudio(path) + play
  → si path == currentPath: play directo
  → _updateButton() → '⏹'

⏹ (reproduciendo) → MusicPlayer.toggle()
  → lee ConfigManager.getPlayerLevel() → resuelve cfg.tracks[level]
  → pause()
  → si path ≠ currentPath: _buildAudio(path)  ← pista actualizada, lista para próximo play
  → si path == currentPath: audio.currentTime = 0
  → _updateButton() → '▶'
```
**Nota:** cambiar Perfil Base en Config llama `MusicPlayer.setTrack(path)` que actualiza
`currentPath` en caliente. El toggle siempre re-verifica el perfil activo.

### 5.8 Render sidebar Mi Deck
```
Engines._renderSidebar()
  → lee _activeTab (engines|decks|staples|favoritas)
  → staples: _renderStaplesItems() → imageUrl (NO img)
  → favoritas: _renderFavoritasItems() → Favoritas.getAll()
```

### 5.9 Scoring G1/G2 (nuevo en v2.2)
```
Stats.calculateInternalScore(cards)
  → loop principal (sin cambios): roleCounters → pilares → rendimientos decrecientes
  → loop paralelo G1/G2:
      por cada carta main:
        segmentDescription(desc) → fragmentos por categoría de nomenclatura
        getRoleBasePower(rol)     → L3 base
        applyLayers(segments)     → L1 × L2 × L4 × L5 (keywords en fragmento correcto)
        getReliability(pool)      → pool efectivo = copias + searchers del mismo arquetipo
        cardScore = basePower × layerMult × reliability
        getRoleG1G2(dominantRole) → 'g1' | 'g2' | 'neutral' (neutral = 50/50)
  → retorna { ...campos anteriores, g1Score, g2Score }

Stats.calculateExternalScore(deckCards, powerScoreCache, metaDecks)
  → flujo anterior intacto
  → al calcular totalThreat: cruza threatCards con g1g2Roles del deck
  → retorna { ...campos anteriores, g1Vulnerability, g2Vulnerability }
```

## 11. CAMBIOS v2.2 — DETALLE POR ARCHIVO

### `buscador.js`
- **`FILTER_DATA.monsterTypes`**: añadido `'Pyro'` (estaba ausente; todos los demás tipos ya existían).
- **`Buscador.randomCard()`**: método nuevo. Llama a `buildApiUrl('')` con los filtros activos, aplica `applyAdvancedLocalFilter` y `applyWordFilters`, elige una carta al azar del pool resultante y la muestra con `displayResults([picked])`. Muestra un notice con el tamaño del pool. Si no hay cartas que cumplan los filtros, muestra mensaje de error.

### `index.html`
- Añadido botón `#random-btn` con clase `btn btn-random` después del botón `#clear-btn` en la barra de búsqueda del Buscador.

### `style_buscador.css`
- Añadida clase `.btn-random`: gradiente `#4a1a6e → #8b2fc9`, texto dorado `#f0d060`, `width:100%`, hover con borde dorado.

### `data.js` — ConfigManager (nuevas estructuras en defaultConfig)
- **`g1g2Roles`**: clasifica cada rol existente como `'g1'`, `'g2'` o `'neutral'`. G1 = construye board/protege combo. G2 = disrumpe/rompe board. Neutral = funciona en ambos contextos.
- **`roleBasePower`**: tabla de poder base L3 por rol (escala 1–10). Negate-activation=10, Boardbreaker=9, Negate-effect/Negater/Tower=8... configurable por el usuario.
- **`scoringLayers`**: capas L1 (velocidad, cat: `condicionActivacion`), L2 (coste, cat: `costoActivacion`), L4 (restricción, cat: `restriccion`), L5 (alcance, cat: `efectoGenerico`). Cada capa tiene `entries: [{keywords, multiplier}]`.
- **`reliabilityTable`**: `{1:0.40, 2:0.65, 3:0.85, 4:0.90, 5:0.95}` — fiabilidad por copias en mano de apertura (deck 40, mano 5).

### `data.js` — ConfigManager (nuevos getters)
Añadidos después de `getRoleCondition`:
- `getG1G2Roles()` / `getRoleG1G2(roleName)`
- `getRoleBasePowers()` / `getRoleBasePower(roleName)` (default: 3 si no existe)
- `getScoringLayers()`
- `getReliabilityTable()` / `getReliability(copies)` (interpolación para valores fuera de tabla)

### `data.js` — ConfigManager (métodos de notContains)
Añadidos después de `removeKeywordFromRoleCondition`:
- `addNotContainsToRole(roleName, kw)` — push a `roleConditions[roleName].notContains[]`
- `removeNotContainsFromRole(roleName, index)` — splice por índice

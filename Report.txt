INFORMACIÓN GENERAL DEL PROYECTO
--------------------------------------------------------------------------------
Nombre: Destiny Draw - Yu-Gi-Oh! App
Plataforma: Web (HTML5, CSS3, JavaScript)
Prioridad: Mobile-First (responsive para PC)
Funciona: SIN SERVIDOR LOCAL (solo necesita un navegador)
Inicio del Proyecto: 07/02/2025
Última Actualización: 07/02/2025 - v1.2.0

OBJETIVO DEL PROYECTO
--------------------------------------------------------------------------------
Crear una aplicación web llamada "Destiny Draw" funcional y sencilla para 
gestionar mazos (decks) de Yu-Gi-Oh!, con capacidades de búsqueda de cartas, 
análisis estadístico, simuladores, información del meta actual, recursos de 
formación y configuración personalizable.

La aplicación está diseñada con arquitectura modular para facilitar el
mantenimiento y escalabilidad futura.

CARACTERÍSTICA CLAVE: Funciona completamente SIN SERVIDOR
- Solo se necesita abrir index.html en cualquier navegador
- La API de YGOPRODeck permite CORS, no requiere backend
- Todos los módulos funcionan client-side

PALETA DE COLORES PRINCIPAL
--------------------------------------------------------------------------------
Color Base: #003366 (Azul marino oscuro)
El esquema de colores está diseñado alrededor de este tono azul profundo,
que da una sensación profesional y relacionada con el tema de Yu-Gi-Oh!

Colores completos:
- Primary: #003366 (Azul marino oscuro - BASE)
- Secondary: #004080 (Azul marino medio)
- Accent: #0066cc (Azul brillante)
- Gold: #FFD700 (Dorado - Yu-Gi-Oh!)
- Background Dark: #001a33
- Background Card: #002b4d
- Text Light: #f1f1f1

API UTILIZADA - YGOPRODECK
--------------------------------------------------------------------------------

URL Base: https://db.ygoprodeck.com/api/v7/cardinfo.php

Parámetros:
- fname: Fuzzy name search (búsqueda parcial por nombre)
- name: Exact name search
- type: Tipo de carta
- race: Raza
- attribute: Atributo
- level: Nivel
- etc.

Ejemplo:
https://db.ygoprodeck.com/api/v7/cardinfo.php?fname=dark

IMPORTANTE: 
- Esta API permite CORS
- No requiere API key
- Funciona sin servidor
- Gratis para uso público

Respuesta JSON:
{
  "data": [
    {
      "id": 12345,
      "name": "Dark Magician",
      "type": "Normal Monster",
      "desc": "...",
      "atk": 2500,
      "def": 2100,
      "level": 7,
      "race": "Spellcaster",
      "attribute": "DARK",
      "card_images": [
        {
          "image_url": "...",
          "image_url_small": "..."
        }
      ]
    }
  ]
}

NOTAS PARA DESARROLLADORES

CÓMO AGREGAR UN NUEVO MÓDULO:

1. Crear archivo CSS en css/ con prefijo "style_"
2. Crear archivo JS en Modules/ (si requiere lógica)
3. Agregar <link> al CSS en index.html
4. Agregar <script> al JS en index.html
5. Crear sección HTML con id="nombremodulo-content"
6. Agregar botón en navegación con data-tab="nombremodulo"
7. Agregar nombre del tab al array Navigation.tabs
8. Integrar Logger.functionStart/End
9. Documentar en Report.txt

CÓMO USAR EL LOGGER:

```javascript
// Al inicio de función
Logger.functionStart('NombreMódulo', 'nombreFunción');

// Info general
Logger.info('NombreMódulo', 'Mensaje', datosOpcionales);

// Errores
Logger.error('NombreMódulo', 'Error', errorObject);

// Click de botón
Logger.buttonClick('button-id', 'Texto', 'NombreMódulo');

// Al final de función
Logger.functionEnd('NombreMódulo', 'nombreFunción', resultadoOpcional);
```

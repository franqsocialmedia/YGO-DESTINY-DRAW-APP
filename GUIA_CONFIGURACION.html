📁 Guía de Configuración

META Tools - Estructura de Carpetas

⚠️ Importante - Lee esto primero

Para que META Tools funcione correctamente, debes crear una estructura de carpetas específica. Esta guía te mostrará paso a paso cómo hacerlo.

📋 Paso 1: Ubicación de los Archivos

1 Coloca todos los archivos en la misma carpeta

Asegúrate de tener los siguientes archivos juntos:

  • index.html - La aplicación principal
  • meta-tools.js - El módulo META Tools

📁 Paso 2: Crear la Carpeta META

2 Crea una carpeta llamada "META"

En la misma ubicación donde están index.html y meta-tools.js, crea una carpeta nueva:

  • El nombre debe ser exactamente: META (en mayúsculas)
  • No uses espacios ni caracteres especiales

📅 Paso 3: Crear la Carpeta de Fecha

3 Dentro de META, crea una carpeta con la fecha de hoy

El formato debe ser: DD-MM-YYYY (día-mes-año)

Ejemplo para hoy (29 de enero de 2026):
Nombre de carpeta: 29-01-2026
Ejemplo para el 5 de febrero de 2026:
Nombre de carpeta: 05-02-2026

Nota: El día y mes deben tener siempre 2 dígitos (usa 01, 02, 03... en lugar de 1, 2, 3...)

📄 Paso 4: Agregar tus Archivos .ydk

4 Coloca tus decks en formato .ydk

Dentro de la carpeta de fecha, coloca tus archivos de deck:

  • Los archivos deben tener extensión .ydk
  • Usa nombres descriptivos (ej: Snake-Eye.ydk, Yubel.ydk)
  • Puedes colocar tantos decks como quieras

🗂️ Estructura Final

Así debe verse tu estructura de carpetas:

📁 [Tu Carpeta de Aplicación]
├── 📄 index.html
├── 📄 meta-tools.js
└── 📁 META/
    └── 📁 29-01-2026/
        ├── 📄 Snake-Eye.ydk
        ├── 📄 Yubel.ydk
        ├── 📄 Centur-Ion.ydk
        └── 📄 Tenpai.ydk

✅ Paso 5: Verificación

✓ Cómo saber si está bien configurado
  1. Abre index.html en tu navegador
  2. Haz clic en la pestaña "META Tools"
  3. En el menú desplegable "Seleccionar Deck META:", deberías ver tus decks listados
  4. Selecciona un deck y debería cargar su información

❌ Solución de Problemas

Error: "No se pudo acceder a la carpeta META/[fecha]/"

  • Verifica: ¿Existe la carpeta META?
  • Verifica: ¿La carpeta de fecha tiene el formato correcto (DD-MM-YYYY)?
  • Verifica: ¿La fecha corresponde al día de hoy?

No aparecen mis decks en el menú

  • Verifica: ¿Los archivos tienen extensión .ydk?
  • Verifica: ¿Están dentro de la carpeta de fecha correcta?
  • Verifica: ¿Los nombres de los archivos no tienen caracteres especiales?

Error al cargar el deck

  • Verifica: ¿El archivo .ydk tiene el formato correcto?
  • Verifica: ¿Tienes conexión a internet? (necesaria para cargar imágenes de cartas)
  • Abre: La consola del navegador (F12) para ver errores detallados

📝 Formato del Archivo .ydk

Tus archivos .ydk deben tener este formato:

#created by...
#main
[ID de carta 1]
[ID de carta 2]
...
#extra
[ID de carta extra 1]
...
!side
[ID de carta side 1]
...

Nota: Se incluye un archivo de ejemplo (EJEMPLO_Snake-Eye.ydk) que puedes usar como referencia.

🔄 Actualización Diaria

📆 Cambio de Fecha

Cada día deberás crear una nueva carpeta con la fecha correspondiente dentro de META si quieres actualizar los decks disponibles.

Puedes mantener carpetas de fechas anteriores para histórico.

📞 Soporte

Si después de seguir esta guía aún tienes problemas:

  1. Revisa el archivo README_META_TOOLS.md para información técnica adicional
  2. Abre la consola del navegador (tecla F12) y busca mensajes de error
  3. Contacta con el desarrollador para asistencia

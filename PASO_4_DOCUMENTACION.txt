RESUMEN EJECUTIVO
--------------------------------------------------------------------------------
Se ha implementado exitosamente el sistema de Nomenclatura de Efectos que
permite identificar y resaltar visualmente las diferentes partes estructurales
de los efectos de las cartas de Yu-Gi-Oh!. Este sistema incluye:

1. Detección automática de 9 categorías de nomenclatura
2. Resaltado visual con marks de colores en CardViewer
3. Tooltips informativos al pasar el cursor
4. Interfaz de configuración completa para personalización
5. Sistema basado en párrafos (delimitados por . : ;)

================================================================================
ARQUITECTURA IMPLEMENTADA
================================================================================

1. CATEGORÍAS DE NOMENCLATURA
--------------------------------------------------------------------------------

El sistema identifica 9 categorías principales de efectos:

a) VELOCIDAD DE EFECTO (effectSpeed)
   - Quick Effect
   - Trigger  
   - Ignition
   
b) TIPO DE EFECTO (effectType)
   - Targeting
   - Non-Targeting

c) TIMING DEL EFECTO (timing)
   - On Summon
   - On Activation
   - During Battle
   - End Phase

d) REQUISITOS (requirements)
   - Condiciones necesarias para activar
   - Array de palabras clave

e) CONDICIÓN DE ACTIVACIÓN (conditions)
   - While
   - During
   - As long as

f) COSTO DE ACTIVACIÓN (cost)
   - Discard
   - Banish
   - Tribute
   - Pay
   - Detach
   - Send

g) EFECTO (effects)
   - Destruction
   - Negation
   - Banish
   - Special Summon
   - Search
   - Draw
   - Burn
   - Gain

h) DURACIÓN DEL EFECTO (duration)
   - Until End Phase
   - Permanent
   - Once While Face-up

i) RESTRICCIÓN (restrictions)
   - Once Per Turn
   - Hard Once Per Turn
   - Cannot Summon
   - Cannot Activate

1. CONFIGMANAGER.JS (MODIFICADO)

NUEVAS FUNCIONES:

getNomenclature()

getNomenclatureColors()

updateNomenclatureColor(category, color)

- Guarda en localStorage
- Formato hexadecimal (#RRGGBB)

COLORES POR DEFECTO AGREGADOS:
- 9 colores distintos para cada categoría
- Paleta armoniosa y legible
- Transparencia aplicada en CSS (0.6)

2. CARDVIEWER.JS (MODIFICADO COMPLETAMENTE)
--------------------------------------------------------------------------------

NUEVAS FUNCIONES:

highlightNomenclature(desc)
- Función principal de resaltado
- Divide descripción en párrafos
- Llama a highlightParagraph por cada uno

splitIntoParagraphs(text)
- Divide texto en párrafos usando delimitadores
- Delimitadores: . (punto), : (dos puntos), ; (punto y coma)
- Retorna array de objetos con texto y posiciones

highlightParagraph(paragraph, nomenclature, colors)
- Analiza UN párrafo completo
- Verifica keywords de cada categoría
- Si coincide, resalta TODO el párrafo
- Retorna HTML con <mark> o texto sin modificar

LÓGICA DE RESALTADO:
1. Se divide el efecto completo en párrafos
2. Cada párrafo se analiza independientemente
3. Se busca si contiene keywords de alguna categoría
4. Si coincide, se resalta el párrafo COMPLETO con el color de esa categoría
5. Solo un color por párrafo (primera coincidencia)

MARKS CON TOOLTIPS:
<mark style="background-color: #FF6B6B; opacity: 0.6; padding: 2px 4px; 
      border-radius: 3px; cursor: help;" 
      title="Velocidad de Efecto">
    When this card is Normal Summoned:
</mark>

El atributo title="" muestra el nombre de la categoría al hacer hover

3. CONFIG.JS (MODIFICADO)
--------------------------------------------------------------------------------

NUEVA SECCIÓN: "Nomenclatura de Efectos"

FUNCIONES AGREGADAS:

renderNomenclatureSection()
- Renderiza sección completa
- Muestra las 9 categorías
- Cada categoría tiene:
  * Nombre (readonly)
  * Color picker
  * Lista de keywords actuales
  * Input para agregar nuevas

renderNomenclatureKeywords(category, categoryData)
- Renderiza chips de keywords
- Maneja dos estructuras:
  * Objetos: { "Nombre": ["kw1", "kw2"] }
  * Arrays: ["kw1", "kw2", "kw3"]

updateNomenclatureColor(inputElement)
- Actualiza color desde color picker
- Guarda en ConfigManager
- No requiere re-render

addNomenclatureKeywordFromInput(inputElement)
- Agrega nueva keyword a categoría
- Maneja estructuras de objeto y array
- Valida duplicados
- Re-renderiza sección

removeNomenclatureKeyword(category, name, keyword)
- Elimina keyword específica
- Limpia objetos vacíos (Custom_*)
- Re-renderiza sección

INTERFAZ VISUAL:
- Tarjetas por categoría
- Color picker integrado
- Chips interactivos con X para eliminar
- Input inline para agregar keywords
- Nombres de categoría en español

FUNCIONAMIENTO DEL SISTEMA
================================================================================

FLUJO COMPLETO:

1. USUARIO ABRE CARTA EN CARDVIEWER
   ↓
2. CardViewer.highlightNomenclature(card.desc)
   ↓
3. splitIntoParagraphs() divide el efecto
   Ejemplo: "When this card is Normal Summoned: You can add 1 card."
   Párrafos:
   - "When this card is Normal Summoned:"
   - " You can add 1 card."
   ↓
4. highlightParagraph() por cada párrafo
   ↓
5. Verifica keywords en orden de prioridad:
   effectSpeed → effectType → timing → requirements → ...
   ↓
6. Si encuentra coincidencia:
   - Obtiene color de la categoría
   - Envuelve párrafo en <mark> con color y tooltip
   - Retorna párrafo resaltado
   ↓
7. Si NO encuentra coincidencia:
   - Retorna párrafo sin modificar
   ↓
8. Todos los párrafos se unen y se muestran en CardViewer

EJEMPLO PRÁCTICO:

Carta: "Ash Blossom & Joyous Spring"
Descripción:
"When a card or effect is activated that includes any of these effects 
(Quick Effect): You can discard this card; negate that effect."

ANÁLISIS POR PÁRRAFOS:

Párrafo 1: "When a card or effect is activated that includes any of 
           these effects (Quick Effect):"
Keywords detectadas: "when", "(quick effect)"
Categoría: timing (primera coincidencia)
Color: #FFE66D (amarillo)
Resultado: <mark style="..." title="Timing del Efecto">...</mark>

Párrafo 2: " You can discard this card;"
Keywords detectadas: "discard"
Categoría: cost
Color: #AA96DA (morado)
Resultado: <mark style="..." title="Costo de Activación">...</mark>

Párrafo 3: " negate that effect."
Keywords detectadas: "negate"
Categoría: effects
Color: #FCBAD3 (rosa claro)
Resultado: <mark style="..." title="Efecto">...</mark>

================================================================================
PERSONALIZACIÓN DESDE CONFIG
================================================================================

USUARIO PUEDE:

1. CAMBIAR COLORES
   - Click en color picker de cada categoría
   - Seleccionar color deseado
   - Cambio se aplica inmediatamente
   - Persiste en localStorage

2. AGREGAR PALABRAS CLAVE
   - Escribir en input de categoría
   - Enter o click en "+ Agregar"
   - Keyword se guarda y aparece como chip
   - Disponible inmediatamente para detección

3. ELIMINAR PALABRAS CLAVE
   - Click en "×" del chip
   - Confirmación automática
   - Re-renderiza sección
   - Cambio se guarda en localStorage

4. EXPORTAR/IMPORTAR CONFIGURACIÓN
   - Botón "Exportar Data" incluye nomenclatura
   - Formato JSON con toda la config
   - Importar restaura keywords y colores

EJEMPLO DE USO:

Usuario quiere agregar "tribute summon" a timing:
1. Va a Config → Nomenclatura de Efectos
2. Busca categoría "Timing del Efecto"
3. Escribe "tribute summon" en input
4. Click en "+ Agregar"
5. Chip aparece en la lista
6. Ahora cualquier párrafo con "tribute summon" 
   se resalta en amarillo (#FFE66D)

================================================================================
CARACTERÍSTICAS TÉCNICAS
================================================================================

1. RESALTADO POR PÁRRAFOS
   - NO resalta palabras sueltas
   - Resalta el PÁRRAFO COMPLETO que contiene la keyword
   - Respeta delimitadores de Yu-Gi-Oh! (. : ;)
   - Un solo color por párrafo (primera categoría que coincida)

2. TOOLTIPS CON TITLE
   - Atributo HTML nativo
   - Funciona en desktop (hover)
   - Funciona en móvil (tap)
   - Muestra nombre en español de la categoría

3. SISTEMA DE PRIORIDAD
   - Categorías se verifican en orden específico:
     effectSpeed → effectType → timing → requirements → 
     conditions → cost → effects → duration → restrictions
   - Primera coincidencia gana
   - Evita resaltados múltiples en mismo párrafo

4. OPACIDAD Y ESTILO
   - Opacity: 0.6 (permite leer texto debajo)
   - Padding: 2px 4px (espaciado cómodo)
   - Border-radius: 3px (esquinas redondeadas)
   - Cursor: help (indica que hay tooltip)

5. ESTRUCTURA FLEXIBLE
   - Soporta objetos: { "Nombre": ["kw"] }
   - Soporta arrays: ["kw1", "kw2"]
   - ConfigManager maneja ambos casos
   - Expansible a nuevas categorías

================================================================================
LIMITACIONES CONOCIDAS
================================================================================

1. UN COLOR POR PÁRRAFO
   - Si un párrafo cumple múltiples categorías
   - Solo se resalta con la primera categoría detectada
   - Orden de prioridad es fijo

2. CASE INSENSITIVE
   - Búsqueda ignora mayúsculas/minúsculas
   - "Quick Effect" detecta "quick effect" y "QUICK EFFECT"
   - No distingue contexto

3. NOMBRES DE CATEGORÍA NO EDITABLES
   - Los 9 nombres están fijos en código
   - Solo se pueden editar keywords y colores
   - Nombres en español hardcodeados en categoryNames

4. DELIMITADORES FIJOS
   - Solo . : ; delimitan párrafos
   - No se pueden personalizar
   - Basado en formato estándar de Yu-Gi-Oh!

1. SPECIALTY-ANALYZER.JS (NUEVO)
--------------------------------------------------------------------------------
Módulo completo de análisis de especialidades

FUNCIONES PRINCIPALES:

analyzeCard(card)
- Analiza una carta individual
- Busca keywords de especialidades en la descripción
- Retorna array de especialidades detectadas
- Incluye datos de counters

analyzeDeck(cards)
- Analiza el deck completo
- Cuenta especialidades por tipo
- Retorna especialización del deck
- Estructura:
  {
    specializations: {
      "NombreEspecialización": {
        deckLevel: "Nombre",
        cardCount: 5,
        counters: [...],
        counteredBy: [...],
        linkedKeywords: [...]
      }
    },
    rawCount: { ... }
  }

getPrimarySpecialization(deckAnalysis)
- Determina la especialización principal del deck
- Basado en la mayor cantidad de cartas
- Retorna nombre, count, counters y counteredBy

calculateCardVsCard(card1, card2) [Preparado para Paso 6]
- Calcula counter score entre dos cartas
- Verifica si card1 contrarresta a card2
- Retorna score numérico

calculateDeckVsDeck(deck1, deck2) [Preparado para Paso 7]
- Calcula counter score entre dos decks
- Retorna: counterScore, interactions, avgCounter
- Base para External Score

renderDeckSpecializations(deckAnalysis)
- Genera HTML para mostrar especialidades
- Ordenado por cantidad de cartas
- Listo para integración UI

   }

Carta: "Harpie's Feather Duster"
Descripción: "Destroy all Spell and Trap Cards..."

Análisis:
→ keyword "destroy" detectado
→ Especialidad asignada:

    keyword: "destroy",
    cardLevel: "Removal",
    deckLevel: "Destruction",
    linkedRole: "Boardbreaker",
    counters: ["monster-effect", "backrow"],
    counteredBy: ["destruction-protection"]

Deck con 8 cartas "Removal":
→ Especialización del deck: "Destruction"
→ Counter potencial contra decks con backrow pesado

CONFIGURACIÓN DESDE UI
================================================================================

USUARIO PUEDE:

1. Crear nuevas especialidades
   - Definir keyword
   - Nombre a nivel carta
   - Nombre a nivel deck
   - Vincular a rol existente

2. Editar especialidades
   - Cambiar nombres
   - Modificar vinculación
   - Renombrar keywords

3. Eliminar especialidades
   - Con confirmación

4. Exportar/Importar
   - Incluye especialidades en backup
   - Formato JSON extendido

EJEMPLO DE USO:

Usuario quiere agregar "shuffle":
1. Va a Config → Especialidades y Counters
2. Escribe "shuffle" en input
3. Click "Crear Especialidad"
4. Edita campos:
   - Carta: "Shuffle"
   - Deck: "Deck Manipulation"
   - Rol: (ninguno)
5. Guardar

Ahora todas las cartas con "shuffle" en descripción
tendrán esta especialidad detectada automáticamente.

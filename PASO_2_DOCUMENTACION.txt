RESUMEN EJECUTIVO
--------------------------------------------------------------------------------
Se ha implementado exitosamente el sistema de Lista de Staples. Este sistema
permite:

1. Mantener una lista interna de cartas genéricas (staples)
2. Asignar roles predefinidos a staples
3. Definir specialty keywords para cada staple
4. Gestionar staples desde Configuración
5. Aplicar automáticamente roles y especialidades de staples al deck
6. Sistema NO visible directamente en la UI del deck (datos internos)

4. SPECIALTY-ANALYZER.JS
--------------------------------------------------------------------------------

MODIFICACIÓN: analyzeCard(card)

NUEVA LÓGICA:
1. Verificar si carta es staple (ConfigManager.isStaple)
2. Si es staple:
   - Obtener specialty keywords del staple
   - Buscar cada keyword en specialties config
   - Agregar a detectedSpecialties con flag fromStaple: true
3. Continuar con detección normal desde descripción
4. Evitar duplicados (keywords ya agregados desde staple)

Resultado: Staples tienen especialidades predefinidas + detectadas

NUEVA FUNCIÓN: getStapleRoles(cardId)
- Retorna roles predefinidos de un staple
- Usado por deck.js para combinar roles

5. DECK.JS
--------------------------------------------------------------------------------

MODIFICACIÓN: syncFromViewer(id, card, qty)

NUEVA LÓGICA AL AGREGAR CARTA:
1. Detectar especialidades (incluye staples automáticamente)
2. Obtener roles automáticos (autoAssignRoles)
3. Si es staple:
   - Obtener roles predefinidos (getStapleRoles)
   - Combinar con roles automáticos
   - Evitar duplicados
4. Crear carta con roles combinados

Resultado: Staples tienen roles automáticos + predefinidos

================================================================================
GESTIÓN DESDE CONFIGURACIÓN
================================================================================

USUARIO PUEDE:

1. VER LISTA DE STAPLES
   Config → Lista de Staples → Ver todas las staples

2. AGREGAR NUEVO STAPLE
   - Ingresar ID de carta (ej: 12345678)
   - Ingresar nombre (ej: "Ash Blossom")
   - Click "Agregar Staple"
   - Se crea con arrays vacíos

3. ASIGNAR ROLES A STAPLE
   - Dropdown con todos los roles disponibles
   - Select rol → se agrega
   - Click × en chip → se elimina

4. AGREGAR SPECIALTY KEYWORDS
   - Input de texto
   - Enter o botón "Agregar"
   - Keywords en lowercase automáticamente
   - Click × en chip → se elimina

5. EDITAR NOTAS
   - Campo de texto editable
   - Cambio automático sin re-render

6. ELIMINAR STAPLE
   - Click botón 🗑️
   - Confirmación con nombre
   - Eliminación permanente

EJEMPLO PRÁCTICO:

Usuario quiere agregar "Ash Blossom & Joyous Spring":

1. Config → Lista de Staples
2. ID: 14558127
3. Nombre: "Ash Blossom y Primavera Jubilosa"
4. Agregar
5. Dropdown → Seleccionar "Handtrap"
6. Input keywords → "negate" + Enter
7. Input keywords → "effect activation" + Enter
8. Notas → "Handtrap universal"
9. Listo

Ahora cuando el usuario agregue Ash Blossom al deck:
- Tendrá rol "Handtrap" automáticamente
- Tendrá especialidades "Negation" y "Effect Activation"
- Se contará en análisis de deck

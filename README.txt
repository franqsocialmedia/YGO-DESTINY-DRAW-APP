DESTINY DRAW YUGIOH APP!

Aplicacion Web para buscar y revisar cartas, construir listas/deckbuilding, comparar decks construidos, descargar o subir tus listas de formatos .ydk o .txt, mini simulador de partida para comparar decks y analizar el meta juego segun las paginas más usadas para el juego digital. Todo en una sola APP.


=============================================

BUSCADOR DE CARTAS:
Busca y filtra las cartas por partes de sus nombres y/o palabras clave separadas por coma.

=============================================

MI DECK:
Desde el Buscador ve agregando cartas a tu lista o deck en las copias que desees. O subelas desde un formato .ydk, .txt o en tus cookies de navegador.

Puedes revisar las estadisticas del deck de las palabras y datos clave de las cartas que lo componen, como el Calculo de Hipergeometria. Y hasta los efectos counter que detienen sus jugadas.

Puedes asignar funciones de las cartas para el deck (starter, booster, extender, etc)

==============================================

SIMULADOR:
Utiliza los decks en .ydk, .txt o guardados en tus cookies para comparar sus estadisticas y pequeños juegos.

Por ultimo puedes ver una simulador de 5 cartas aleatorias para ver probabilidad de cartas.

===============================================

META ANALISYS:
Lista de paginas hechas por fans para mostrar el Meta Game de hoy en dia y revisar las mejores cartas para usar.
